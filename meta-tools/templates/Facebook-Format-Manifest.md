# Facebook Format Manifest

This manifest defines the structure for Facebook post captions for full-length song video releases. Use the corresponding sunodoc .md file for each song to analyze and populate specific details (e.g., themes, production notes). Captions should be concise (150-300 words) for engagement. Replace placeholders with song-specific content.

## Template Structure

```
🎧 [Song Title] — [Artist (e.g., Sky.AI or After Brügge)]

[Brief summary sentence, analyzed from sunodoc for themes/emotion.]

🔗 Listen here: https://open.spotify.com/artist/3NqNiVvNvYg9j8wYSy6YQc

🤖 What is [Artist]? [Short explanation, e.g., AI art project or legacy restoration.]

⚙️ Credits: Lyrics & direction by Skydevaaben, AI tool: [Tool] (curated by rights holder).

📌 Connect: Facebook @skydevaben | Instagram/TikTok @skydevaaben | Linktree: https://linktr.ee/skydevaaben

🗣️ [CTA, e.g., "Comment your reaction! Share with friends who love synth."]

#Tags #SkyAI #Skydevaaben #Synthpop #Synthwave #Retrowave #ElectronicMusic #AIEnhanced #Transparency #MusicVideo
```

## Usage Notes
- Analyze the sunodoc .md file for each song to customize the summary, explanation, credits, and CTA.
- Use inline links and emojis; encourage comments/shares for community.
- Post as a video with the song.
