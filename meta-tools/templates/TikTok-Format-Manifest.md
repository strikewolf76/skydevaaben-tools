# TikTok Format Manifest

This manifest defines the structure for TikTok video captions for full-length song releases. Use the corresponding sunodoc .md file for each song to analyze and populate specific details (e.g., themes for hooks). Captions should be short (50-100 words) for quick engagement. Replace placeholders with song-specific content.

## Template Structure

```
🎧 [Song Title] — [Artist (e.g., Sky.AI or After Brügge)]

[1-2 sentence hook/summary, analyzed from sunodoc for themes/emotion.]

🤖 [Artist] = [Short blurb, e.g., transparent AI art project.]

⚙️ By Skydevaaben, AI tool: [Tool] (curated).

📌 @skydevaaben | Link in bio: Spotify etc.

🗣️ [CTA, e.g., "Duet if this hits! Share your story."]

#Tags #SkyAI #Skydevaaben #Synthpop #Synthwave #Retrowave #ElectronicMusic #AIEnhanced #Transparency #MusicVideo #Viral
```

## Usage Notes
- Analyze the sunodoc .md file for each song to customize the hook, blurb, credits, and CTA.
- Use trending sounds, emojis, and hashtags for virality.
- Post as a full video with song audio.
