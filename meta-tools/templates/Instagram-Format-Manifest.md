# Instagram Format Manifest

This manifest defines the structure for Instagram post captions for full-length song video releases. Use the corresponding sunodoc .md file for each song to analyze and populate specific details (e.g., themes, production notes). Captions should be concise (150-300 words) for engagement. Replace placeholders with song-specific content.

## Template Structure

```
🎧 [Song Title] — [Artist (e.g., Sky.AI or After Brügge)]

[Brief summary sentence, analyzed from sunodoc for themes/emotion.]

🔗 Listen in bio or comments.

🤖 What is [Artist]? [Short explanation, e.g., transparent AI art project or legacy restoration.]

⚙️ Credits: Lyrics & direction by Skydevaaben, AI tool: [Tool] (curated by rights holder).

📌 Connect: @skydevaaben (IG/TikTok/FB) | Spotify: https://open.spotify.com/artist/3NqNiVvNvYg9j8wYSy6YQc

🗣️ CTA: [Song-specific, e.g., "Comment your take on AI vs art! Share with friends."]

#Tags #SkyAI #Skydevaaben #Synthpop #Synthwave #Retrowave #ElectronicMusic #AIEnhanced #Transparency #MusicVideo
```

## Usage Notes
- Analyze the sunodoc .md file for each song to customize the summary, explanation, credits, and CTA.
- Use emojis for visual appeal; link key URLs in bio.
- Post as a video reel or story with the song audio.
